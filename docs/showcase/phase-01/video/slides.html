Hai loại token

Access token (JWT)

Sống 15 phút. Gửi trong header Authorization.

API chỉ kiểm chữ ký, không cần tra database, nên mọi instance đều xác thực được.

Refresh token

Sống 7 ngày. Nằm trong cookie httpOnly: JavaScript không đọc được.

Database chỉ lưu SHA-256 của nó. Thu hồi được bất cứ lúc nào.

Xoay vòng và phát hiện token bị đánh cắp

sequenceDiagram
  participant U as Người dùng
  participant K as Kẻ trộm (có R1)
  participant A as API
  U->>A: refresh bằng R1
  A-->>U: cấp R2, thu hồi R1
  K->>A: refresh bằng R1
  A->>A: R1 đã thu hồi → thu hồi cả họ
  A-->>K: 401 REFRESH_TOKEN_REUSED
  U->>A: refresh bằng R2
  A-->>U: 401: đăng nhập lại

Hai request cùng lúc: chỉ một thắng

UPDATE refresh_tokens
SET    revoked_at = now()
WHERE  token_hash = $1
  AND  revoked_at IS NULL      -- điều kiện chính là "khóa"
  AND  expires_at > now()
RETURNING id, user_id, family_id;

Request A: 200Request B: 401 — PostgreSQL khóa dòng, B thấy revoked_at đã có giá trị.
