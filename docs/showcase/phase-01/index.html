Sơ đồ

Vẽ từ docs/showcase/phase-01/README.md; trên GitHub, file đó hiển thị đúng các sơ đồ này.

Đang vẽ sơ đồ…

1Đăng nhập theo vai trò

Đăng nhập bằng tài khoản seed. API trả access token trong body; refresh token nằm trong cookie httpOnly, nên JavaScript của trang này không đọc được.

2Refresh token xoay vòng

Mỗi lần refresh, token cũ bị thu hồi và token mới được cấp. Hai kịch bản bên dưới chạy trên server demo, vì trình duyệt không tự gửi lại được cookie cũ.

3Danh mục và sơ đồ ghế

Không cần đăng nhập. Chọn một đêm diễn để vẽ toàn bộ ghế từ GET /performances/:id/seats.

4Ban tổ chức tạo và công bố đêm diễn

Hãy đăng nhập bằng Ban tổ chức ở bước 1. Đêm diễn mới ở trạng thái DRAFT nên khách chưa thấy; sau khi công bố thì ai cũng thấy.

Body tạo đêm diễn (sửa được)

5Một định dạng lỗi cho mọi trường hợp

Lỗi nào cũng có dạng { code, message, details }. Client rẽ nhánh theo code, không dựa vào câu chữ.

Nhật ký request
